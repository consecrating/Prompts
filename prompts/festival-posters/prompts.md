# Festival & Event Poster Design Prompts (100)

> Professional poster design prompts optimized for ChatGPT, Gemini, NanoBanana, and Grok.
> Every prompt includes anti-clutter and text-readability rules to prevent common AI generation failures.

---

## ⚠️ ChatGPT Image Generation Rules (Applied to ALL prompts below)

```
CRITICAL RULES FOR THIS IMAGE:
- ALL text must be EXTREMELY LARGE and BOLD — minimum 30% of image width for headlines
- Text color MUST contrast with background: white/light text on dark backgrounds, dark text on light backgrounds — NEVER dark text on dark background
- Maximum 3 text elements total (headline + date + one detail) — NO stuffing, NO clutter
- Leave 40% of the image as clean breathing space — whitespace is mandatory
- NO generic office buildings, NO hypothetical corporate buildings, NO stock-photo buildings
- Layout must be CLEAN and MINIMAL — if it looks busy, remove elements until it doesn't
- Text must be READABLE at phone-screen size (imagine viewing on a 6-inch screen)
```
