# Feature 1: Prompt Mixer Engine

## What It Does

Combines any two prompts from different categories to create hybrid scenes with proper lighting reconciliation and environmental logic.

## How to Use

1. Pick any two prompts from different categories (e.g., `P-005` + `NN-003`)
2. Apply the Mixer Formula below
3. Get a coherent hybrid that doesn't look like two images mashed together

## The Mixer Formula

```
HYBRID = [Subject from Prompt A] + [Environment from Prompt B] + [Reconciled Lighting] + [Unified Color Science]
```

### Reconciliation Rules

| Conflict | Resolution |
|---|---|
| Indoor subject + outdoor environment | Subject takes environment's ambient light; add one motivated practical source |
| Warm lighting + cool environment | Use complementary: warm on subject, cool on background — creates natural separation |
| Studio subject + street environment | Remove studio light, replace with nearest available environmental source |
| Day prompt + night prompt | Commit to one time; adjust subject wardrobe/expression to match |
| Close-up subject + wide landscape | Place subject at environmental scale; adjust focal length to maintain both |

Hair fans upward in corona. Limestone formations provide ancient architectural context. Air bubbles escape from fabric folds. 16mm wide dome port, natural light from above.

## Rules for Good Mixes

1. **One subject source, one environment source** — never mix two subjects
2. **Commit to one lighting physics** — the environment determines the light
3. **Maintain the anti-AI rules from both sources** — textures, imperfections, material accuracy all carry over
4. **The subject must BELONG** — adjust wardrobe/styling to be environmentally plausible
5. **Color science follows the environment** — the subject receives the environment's grade
